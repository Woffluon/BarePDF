BarePDF Web Typography Package — Font Inventory, Verification, and Licenses
============================================================================

Scope & CSP Compliance
----------------------
- Target destination in repository: website/public/fonts/
- Content-Security-Policy (website/src/layouts/BaseLayout.astro):
    font-src 'self'; style-src 'self' 'unsafe-inline';
- Zero external CDN requests, zero Google Fonts requests, zero runtime network calls.
- Desktop Slint application (crates/barepdf-ui) keeps native OS system fonts and does not bundle these web fonts.
- Website base path compatibility (website/astro.config.mjs: base = '/BarePDF'):
    All @font-face src URLs must resolve via `${baseUrl}/fonts/<filename>`
    where `baseUrl = import.meta.env.BASE_URL.replace(/\/$/, '')` (yielding `/BarePDF/fonts/...` in production).
