# Keyboard Shortcuts Reference

BarePDF provides keyboard shortcuts for fast document navigation, mirroring the application's global key handler (`crates/barepdf-ui/ui/app_window.slint`).

## File

| Action | Primary Shortcut | Alternative Shortcut |
| :--- | :--- | :--- |
| **Open Document** | `Ctrl+O` | Drag & drop file |
| **Save Annotations** | `Ctrl+S` | Toolbar save |
| **Save Annotations As** | `Ctrl+Shift+S` | Toolbar export |
| **Print Document** | `Ctrl+P` | Toolbar print |

## Navigation

| Action | Primary Shortcut | Alternative Shortcut |
| :--- | :--- | :--- |
| **Command Palette HUD** | `Ctrl+K` | Toolbar search icon |
| **Find in Text** | `Ctrl+F` | Toolbar find |
| **Next Page** | `PageDown` | `→`, `↓`, or `Space` (presentation) |
| **Previous Page** | `PageUp` | `←`, `↑`, or `Backspace` (presentation) |
| **First Page** | `Home` | |
| **Last Page** | `End` | |
| **Toggle Bookmark** | `Ctrl+D` | Sidebar bookmarks |

| Action | Primary Shortcut | Alternative Shortcut |

| **Zoom In** | `+` or `=` | |
| **Zoom Out** | `-` | |

| **Rotate Clockwise** | `Ctrl+R` | Toolbar rotate |
| **Rotate Counter-Clockwise** | `Ctrl+Shift+R` | |
| **Full Screen** | `F11` | |
| **Presentation Mode** | `F5` | |
| **Invert Colors** | `Ctrl+I` | Command Palette |
